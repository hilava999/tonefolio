# ToneFolio

A free portfolio and illustration website theme built by an artist, for artists.

[🖥️ Live Demo](https://demo-tonefolio.pages.dev/) | [📕 Documentation](https://hilava.gitbook.io/tonefolio/)

![Top Page](./doc/00.png)

## ✨️ Features

- **Easy Updates without Coding** (Powered by Sveltia CMS)
- **Masonry Layout**
- **Image Lightbox** (Powered by PhotoSwipe)
- **Tag Filtering**
- **OGP Support & Fully Responsive**
- **NSFW / R-18 Content Cushion Feature**

## 🚀 Get Started

Click **"Use this template"** on GitHub to get started!  
For more details, please check the [Documentation](https://hilava.gitbook.io/tonefolio/).
